Entrega: Resumo de arquivos produzidos e rastreabilidade para qualidade.

Bloqueio: Não produzir valores de catálogo por geração de linguagem. Sem evidência, needs_info.

## Inspeção estruturada

No diagnóstico com inspeção, o código exige snapshot imutável, hash, revisão humana e anexo correspondente ao pedido/revisão. inspecao-tecnica.json e fontes-inspecao.json são evidências de coleta, não dados aprovados para importação. IDs técnicos de observação nunca substituem SKU. Nenhuma imagem foi baixada ou retocada por esse fluxo.
