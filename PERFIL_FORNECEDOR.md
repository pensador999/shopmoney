# Amostra de entrada (dados sintéticos)

Use `npm run demo` para gerar um exemplo. Para receber outro fornecedor, configure o mapeamento na tela. Não atribua tamanhos, categorias ou preços da BRK a outro cliente.

Colunas do exemplo: product_id,title,sku,price,barcode,vendor,size,description.

Cada linha é uma variante; product_id agrupa o pai. SKU e barcode são texto; price usa ponto decimal. supplierKey identifica o fornecedor dentro do cliente. Opções suportam até três dimensões aprovadas. Imagem opcional é somente referência para conferência, sem inclusão no CSV Shopify.
